## 一、先把"三网直连"这件事讲明白

很多人以为"直连"就是机房拉了根线直通国内，这话对了一半。真正影响体验的不是去程，而是**回程**——你的 VPS 把数据发回国内用户时走的那段路。

国内三家运营商（电信、联通、移动）各有自己的"精品出口"，名字看着像乱码，但其实分工很清楚：

- **CN2 GIA（AS4809）**：中国电信的高端骨干网， congestion 比 163 普通骨干低一大截，电信用户走这条回程延迟最低、最稳。
- **AS9929**：联通的精品国际线路，晚高峰拥堵程度比普通联通出口好不少，吞吐更一致。
- **CMIN2（AS58807）**：中国移动国际网络二代，移动用户的回程主力，持续性能扎实。

单线优化的商家，只优化了三家里的某一家——比如只走 CN2，那联通和移动用户照样堵。真正的"三网直连"，是**回程智能调度**：电信用户走 CN2、联通走 9929、移动走 CMIN2，三家运营商的用户都能拿到该有的速度。
